# SinSyn - Sinusoidal Synthesizer

A browser-based web application for audio synthesis with sine waves.

<b>Online demo</b>: [www.source-code.biz/sinSyn](http://www.source-code.biz/sinSyn)<br>

<b>Related work</b>

* [Delphi-SinSyn](https://github.com/tothpaul/Delphi-SinSyn) - Delphi version of SinSyn by Paul Toth
* [HarmSyn](https://www.source-code.biz/harmSyn/) - Harmonic Synthesizer
* [KlattSyn](https://www.source-code.biz/klattSyn/) - Klatt Synthesizer
* [NoiseSyn](https://www.source-code.biz/noiseSyn) - Spectral noise synthesizer
* [SpecSyn](https://www.source-code.biz/specSyn) - Spectral Harmonic Synthesizer
